# Frontend Design System

## Design Philosophy

Industrial Maintenance Command Center

Focus:

* Clean
* Professional
* Enterprise Grade
* Minimal
* High Readability

## Color Palette

Background: #F7F5F2

Surface: #FDFCFB

Primary Cream: #CFC0BD

Secondary Sage: #B8B8AA

Charcoal Slate: #3A3D3F

Success: #7D9A72

Warning: #D96C4A

Danger: #7A2E2E

## UI Principles

* No gradients
* No glassmorphism
* No neon effects
* No excessive animations
* Consistent spacing
* Soft shadows only
* Professional typography

## Main Screens

* Dashboard
* Alerts
* Upload Manuals
* Inventory
* Work Orders
* AI Assistant

## Layout Rules

* Fixed Sidebar
* Top Navigation Bar
* Responsive Dashboard Grid
* Card Based Design
