# Week 1 Plan

## Objective

Build the Manual Ingestion and RAG Foundation for the Maintenance Assistant System.

## Week 1 Scope

* Collect sample machinery manuals
* Extract text from PDF manuals
* Preserve document structure and metadata
* Design chunking strategy
* Generate embeddings
* Store embeddings in vector database
* Test retrieval on sample maintenance queries

## Deliverables

* Manual upload pipeline
* Parsed manual content
* Chunked documents
* Vector database setup
* Working retrieval prototype

## Success Criteria

* Manual content can be extracted successfully
* Relevant chunks are retrieved for maintenance related queries
* Retrieval results include source information
* Foundation ready for IoT integration in Week 2

## Team Notes

This week focuses only on document understanding and retrieval. Agent workflows, IoT integration, and prescriptive maintenance generation will be implemented in later phases.
